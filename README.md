## 🚀 Funcionalidades da Interface

* **Player Responsivo 16:9 Oficial:** Troca dinâmica e instantânea do vídeo ativo via YouTube Embed API com autoplay ao selecionar na playlist.
* **Playlist Inteligente com 10 Vídeos:** Thumbnails reais em alta resolução vindas do YouTube, filtros por categorias (*Agendamentos, Coordenação, Backoffice / ADM, Instrutor*), status de assistido e barra de progresso geral.
* **Checklist Prático:** Roteiro de passos associado a cada vídeo com persistência no LocalStorage.
* **Busca Global em Tempo Real:** Filtro textual instantâneo (com atalho `/`).
* **Modais de Suporte e Documentação Escrita:** Resumos dos tópicos e formulário de chamado.
